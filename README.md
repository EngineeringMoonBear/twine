# Twine

Clickable prototype of a friendship-and-dating app where cis women and trans women meet as friends, allies and more.
Swipe deck, nearby grid, moderated live rooms, mixers/events and chats. All people shown are fictional sample data.

- Source: `index.html` (also published as a claude.ai artifact)
- Site: `./build.sh` writes `docs/`, which GitHub Pages serves at https://twine.joshedunbar.com
